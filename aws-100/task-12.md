# AWS Task 12: Attach Volume to EC2 Instance

## Step 1: Login to AWS Portal

Login to the AWS portal.

## Step 2: Navigate to EC2 Instances

Go to the **EC2** instance section.

## Step 3: Attach Volume

Select the EC2 instance and click the **Attach** button in the **Actions** menu.

## Step 4: Configure Volume

Attach the already created volume with the specific type.

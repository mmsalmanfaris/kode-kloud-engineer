# AWS Task 13: Create EC2 Image from Instance

## Step 1: Login to AWS Portal

Login to the AWS portal.

## Step 2: Select EC2 Instance

Select the EC2 instance you want to create an image from.

## Step 3: Create Image

In the **Actions** menu, go to the **Image and templates** tab and select **Create image**.

## Step 4: Add Image Name

Enter a name for the image.

## Step 5: Wait for Status

Wait for the image status to become **Available**.

# AWS Task 14: Terminate EC2 Instance

## Step 1: Login to AWS Portal

Login to the AWS portal.

## Step 2: Open EC2 Instances

Go to the **EC2** instance tab.

## Step 3: Select the Instance

Select the instance you want to terminate.

## Step 4: Terminate the Instance

From **Instance state**, click **Terminate instance**.

## Step 5: Wait for Deletion

Wait until the instance is deleted.

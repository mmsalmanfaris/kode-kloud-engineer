# AWS Task 2: Security Group Configuration

## Step 1: Login to AWS Portal

Login to the AWS portal.

## Step 2: Search for Security Group

Search for **Security Group** in the AWS console.

## Step 3: Create a New Security Group

Create a new security group with the required name.

## Step 4: Create Inbound Rules

Create inbound rules for the following:
- **HTTP**: Allow traffic on port 80
- **SSH**: Allow traffic on port 22

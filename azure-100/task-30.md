# Azure Task 30: Create Azure SQL Database

## Step 1: Login to Azure Portal

Login to the Azure portal.

## Step 2: Search Azure SQL Database

Search for **Azure SQL Database** in the Azure portal.

## Step 3: Create Database and Server

Create a new database and a new server:
- Use **SQL authentication** so you can add a username and password
- Configure the **compute** and **storage** settings

## Step 4: Enable Public Endpoint

In the **Networking** section, enable the **public endpoint**.

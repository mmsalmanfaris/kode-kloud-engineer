# Azure Task 38: Upload File to Private Container

## Step 1: Login to Azure Portal

Login to the Azure portal.

## Step 2: Create Storage Account

Create a storage account with the given name and server location.

## Step 3: Create Private Container

Create a private container in the storage account.

## Step 4: SSH into the VM and Create a File

```bash
ssh <user>@<ip address>
```

```bash
touch <filename>
```

```bash
vi <filename>
```

Add the required content to the file.

## Step 5: Copy and Run the CLI Command

Copy the CLI command provided in the task.

## Step 6: Get Storage Account Key

Copy the storage account key from the **Security + networking** tab.

## Step 7: Run the Command

Paste and run the command using the storage account key.

## Step 8: Verify Upload

Check that the test file exists in the container.
